Set up sync

This takes about 5 minutes in the Cloudflare website. It gives GhostReader a private place to keep your books and reading progress so every device matches.

1. Make storage (R2)

  1. Open dash.cloudflare.com and sign in. Go to R2 Object Storage.
  2. Tap Create bucket. Name it ghostreader. Leave everything else as is. (R2 asks for a card to turn on; the free amount is 10 GB.)

2. Make the sync worker

  1. Go to Workers & Pages → Create → Create Worker. Name it ghostreader-sync and tap Deploy.
  2. Tap Edit code. Select everything in the editor and delete it.
  3. Tap this button, then paste into the editor:
  4. Tap Deploy.

3. Connect the storage and a key

  1. Open the worker's Settings → Bindings → Add → R2 bucket. Variable name: BUCKET. Pick the ghostreader bucket. Save.
  2. In Settings → Variables and Secrets → Add: type Secret, name SYNC_KEY, value: a long password you make up. Deploy.
  3. Copy the worker address shown at the top of the page. It ends in .workers.dev.

4. Turn it on in GhostReader

  1. Open GhostReader and scroll to the bottom of the library. Tap Sync.
  2. Paste the worker address and your SYNC_KEY, then Save & sync.
  3. Do the same on your other devices with the same address and key.

Audiobooks aren't synced (the free plan limits upload size); add them on each device. Deleting a book on one device doesn't delete it on the others.
